# 03 · 功能使用说明

> Smart VCard · Indigo Grid Edition（靛格制签）
> 面向最终用户。所有描述均与当前代码一致。

## 一、界面总览

应用共 5 个页面：

| 页面 | 路径 | 用途 |
|---|---|---|
| 首页 | `#/` | 品牌介绍、能力清单、三步流程、隐私承诺 |
| 制签工坊 | `#/generator` | 填写信息、实时校样、导出与分享 |
| 关于 | `#/about` | 设计原则、技术栈、互操作说明、许可 |
| 分享页 | `#/?v=…` | 扫码后看到的成品名片与保存入口 |
| 404 | 任意未匹配路径 | 返回首页 |

顶栏右侧可一键切换 **中 / EN**，选择会被记住在本机。

## 二、填写名片

点击「存入名片库」可以保存当前名片。若库中已有同名条目，按钮会显示「更新名片库中的『姓名』」。点击后，当前内容会替换该条目。若要保留两份，可先在库中重命名原条目，再保存当前名片。

进入「制签工坊」，页面左侧为四个分组（编号徽标 01–04）：

1. **身份**：名、姓、中间名、昵称、称谓、后缀、生日、头像链接。
2. **联络**：手机、工作电话、邮箱、工作邮箱、个人网站、公司网站。
3. **机构**：公司 / 机构、职位、品牌简称、一句话介绍、Logo、工作地址。
4. **补充**：LinkedIn、X / Twitter、微信号、备注。

规则：

- 除「名」外全部可选；空字段不会生成空的 vCard 属性。
- 名片与二维码随输入实时更新（约 220ms 防抖）。
- 草稿在停顿约 1.2 秒后自动保存到本机；Logo 单独保存，刷新不丢。
- 字段接近字数上限时，标签旁显示 `已用/上限`（达到上限变红）。
- 表单校验：http(s) URL 白名单、邮箱格式、电话字符集、真实日历日期、逐字段长度上限。

## 三、二维码（右侧校样下方 · 交付台 01–03）

### 01 二维码承载

- **网页链接**（默认）：扫码打开分享页，点一下即可保存联系人；微信可用。
- **原生 vCard**：系统相机直接识别；微信扫码器不认，仅建议 iOS / 安卓相机场景。
- 链接模式下会显示分享链接，可一键复制。

### 02 模块样式与墨色

- 模块样式：方块 / 圆角 / 圆点；定位角始终为实心方块以保证识别率。
- 墨色：靛蓝（默认）/ 墨蓝 / 松绿 / 石板 / 纯黑 / 自定义取色；始终白底，四角静区保留。

### 03 尺寸与导出

- PNG 尺寸：512 / 1024 / 2048 px（内容过密时自动放大并如实提示与命名）。
- 导出按钮：**下载 .vcf**、**下载 PNG**、**下载 SVG**、**下载 PDF**（A6 矢量，交印刷店）、**打印名片**（A6 排版）。
- 复制按钮：**复制 vCard**（vCard 文本）、**复制二维码图片**（直接粘贴进微信 / 邮件 / 文档；浏览器不支持时自动改为下载 PNG 并提示）、**分享**（系统分享面板）。
- 载荷超限（>2200 B）时给出可操作提示，而非让页面崩溃。

## 四、导入 vCard

- 工坊顶部「导入 .vcf」：选择文件或粘贴文本。
- 可识别 vCard 3.0 / 4.0、折行、分组（`item1.TEL`）、参数（含引号包裹值）、RFC 6868 `^` 转义、转义分隔符。
- 文件上限 256KB / 65,536 字符；超过会提示「文件过大」。
- 一个文件含多张名片时：载入第 1 张，并提示「检测到 N 张名片」。
- LOGO 回到 Logo 栏、PHOTO 回到头像栏，不会串位；「品牌简称」「标语」以 `X-SMARTVCARD-*` 承载，往返不丢。

## 五、清空与保存

- 「保存并校样」：把当前内容写入本机草稿（不上传）。
- 「清空」：需二次确认；会同时清除表单、Logo 与本地草稿。

## 六、分享页（对方看到什么）

- 顶部「自己做一张 →」可跳转工坊。
- 主按钮「保存到通讯录」下载 .vcf；次按钮复制 vCard 文本 / 分享。
- 微信内置浏览器中会提示「在浏览器打开」。
- 链接无效 / 被截断时显示引导页，可一键去自己生成。
- 分享链接不含 Logo 图片；不可信链接只保留 http(s) URL。

## 七、打印

- 交付台「打印名片」只输出名片本体（A6 竖版），界面其他部分不进入打印。
- 需要交印刷店时用「下载 PDF」：矢量、A6、二维码居中。

## 八、离线使用

- 首次访问后可安装到主屏（PWA）；离线状态下工坊、导出、导入均可用。

## 九、常见问题

| 问题 | 处理 |
|---|---|
| 二维码扫不出 | 看校样旁状态徽章；「内容过长」时缩短备注或改用网页链接 |
| 导出 PNG 尺寸变了 | 内容过密时为保证可扫会自动放大，Toast 与文件名都会说明实际尺寸 |
| 刷新后 Logo 没了 | 不会：Logo 独立保存；若旧版本数据会在首次打开时自动迁移 |
| 复制图片变成下载 | 浏览器不支持图片剪贴板，属正常降级 |
| 链接在微信里打不开 | 让对方点右上角 ··· →「在浏览器打开」 |
| 中文界面英文名被排反 | 姓名顺序按名字本身是否含 CJK 判定，卡片与 vCard 共用 `formatFullName`，始终正确 |
