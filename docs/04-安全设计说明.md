# 04 · 安全设计说明

> Smart VCard · 审查范围：`src/` 全部源码、`index.html`、`vite.config.ts`、`public/`、`scripts/`、依赖树、`dist/` 产物。
> 方法：逐文件人工审查 + 静态隔离守卫测试（自动化）+ `npm audit`（官方 registry）+ 浏览器实测 + 106 项自动化测试。

## 一、总体结论

- 本项目为**纯浏览器静态应用**：无后端接口、无数据库、无鉴权、无服务端模板，SQL 注入 / 越权 / 服务端 SSRF 等类别**不适用**。
- 主要风险面为：**XSS、不可信分享链接、URL scheme 注入、文件名注入、依赖漏洞、第三方请求泄露、PDF 生成链路**。
- 上述风险点均已处理；生产依赖 `npm audit --omit=dev` 结果为 **0 漏洞**。
- 全量（含 dev 依赖）有 **12 条**公告（2 low、10 moderate），全部位于**构建期 / 静态分析期工具链**（eslint、vite、workbox、typescript-eslint 家族），不会进入 `dist/` 产物——由 `tests/security.test.ts` 对 dist 的守卫测试持续验证。

## 二、安全架构：静态隔离守卫（自动化证据）

借鉴同类项目的安全测试套件，落地为 `tests/security.test.ts`（5 项，全部通过），把「自包含」从承诺变为可执行的自动化守卫：

| 守卫 | 断言内容 |
|---|---|
| ① 无第三方引用 | dist 全部交付文件中，`src=`/`href=`/`@import`/`url()`/`fetch()`/`import()` 五类模式不得出现站外 origin |
| ② 无内联脚本 / 事件属性 | 构建产物 HTML 中每个 `<script>` 必须带 `src`；不得出现 `on*=` 属性 |
| ③ CSP 指令逐条断言 | `default-src 'self'`、`script-src 'self'`（禁 unsafe-inline/eval）、`object-src 'none'`、`frame-src 'none'`、`base-uri 'self'`、`form-action 'self'`；`style-src` 允许 `'unsafe-inline'`（Tailwind v4 运行时样式与内联 style 属性所需，已注释原因） |
| ④ 无 console 噪声 | `src/` 全部源码不得出现 `console.*` 调用 |
| ⑤ 无动态求值 | dist 产物 JS 不得出现 `eval(` 或 `new Function(` |

CSP 由 `vite.config.ts` 的 `contentSecurityPolicy()` 插件在生产构建时注入为 `<meta>`，仅作用于 dist，开发态不注入。

## 三、逐项安全设计

### 3.1 XSS / HTML 注入

| 检查点 | 结论 |
|---|---|
| `dangerouslySetInnerHTML` | **无**。 |
| 用户输入直接拼入 HTML | **无**。动态文本均经 React 文本节点渲染。 |
| 二维码 SVG 拼接用户输入 | 仅拼接经 `normalizeQrColor` 校验的 6 位 hex 与几何数据；载荷只影响模块矩阵。 |
| 分享链接不可信输入 | `decodeSharePayload`：长度上限、JSON 形态校验、`mergeWithDefaults` 逐字段截断 + 控制字符剥离、URL 字段仅保留 http(s)、`logoUrl` 永远拒绝。 |
| 导入 .vcf 不可信输入 | 字符上限、`mergeWithDefaults` 消毒、PHOTO/LOGO 仅接受 http(s)。 |
| 全局错误覆盖层 | 使用 `textContent`，不解析 HTML。 |

**结论**：未发现可利用的 XSS 路径。

### 3.2 URL scheme 注入

- `isHttpUrl`：仅 `http:`/`https:`，拒绝 `javascript:`/`data:`/`file:`，拒绝控制字符与空白字符 trick，长度上限 2048。
- 头像 / Logo：http(s) 或 `data:image/<raster|svg>;base64`；SVG 经 `<img>` 加载不执行脚本。
- 电话号码：仅 `数字 + - ( ) 空格`，4–40 字符。
- 所有导出文件名经 `sanitizeFilename`（路径分隔符、控制字符、Windows 保留名、长度）。

### 3.3 隐私

- 无账号、无上传、无统计、无第三方请求（守卫①证明）。
- 分享链接数据位于 URL `#` 片段，不发送给托管方；Logo 不上链接。
- 本机存储四项：`smart-vcard-draft-v1`（草稿）、`smart-vcard-logo-v1`（Logo）、`smart-vcard-settings-v1`（样式设置）、`smart-vcard-lang`（语言）；均为用户数据，不含密钥。
- 源码无 `console.*`（守卫④），日志不泄露联系方式。

### 3.4 PDF 生成链路

- 库：jspdf 4.2.1 + svg2pdf.js 2.9.0，**运行时动态加载**，不参与首屏包体。
- jspdf ≤4.2.0 存在 12 条 critical 级公告（DoS / 路径遍历 / addJS 与 AcroForm 注入 / XMP 注入等）；**已升级至 4.2.1 全部修复**（`npm audit --omit=dev` 0 漏洞）。
- 适用性分析：本应用只用 `new jsPDF()` + `svg2pdf()` 绘制自有几何 + `output("blob")`，**不调用** addJS / AcroForm / addImage(BMP/GIF) / html() 等公告涉及 API；输入为本应用生成的 SVG，不含外部内容。
- CSP `object-src 'none'`、`frame-src 'none'` 对 PDF 无影响（PDF 经下载交付，不在页面内嵌）。

### 3.5 依赖审计

| 范围 | 结果 |
|---|---|
| 生产依赖（`--omit=dev`） | **0 漏洞**（官方 registry） |
| 全量（含 dev） | 12 条（2 low / 10 moderate），全部位于构建期工具链，不进入 dist（守卫①⑤验证） |
| 运行时动态加载依赖 | jspdf@4.2.1、svg2pdf.js@2.9.0（dependencies） |

### 3.6 交付安全

- 交付包 `npm run archive` 仅包含白名单目录（`src/` / `public/` / `scripts/` / `tests/` / `docs/` + 根配置文件），排除 `node_modules`、`.git`、日志、zip。
- 任何 `.env` 与密钥目录均不进入交付包；本项目无密钥，配置项均在代码中（见 [02-环境部署教程](02-环境部署教程.md) 第七节）。

## 四、输入校验与降级策略

| 场景 | 处置 |
|---|---|
| 分享链接注入非 http URL（`javascript:` 等） | 解码时被清洗为空，卡片不渲染恶意链接 |
| 分享链接超长 / 畸形 / 非 JSON | 拒绝并显示「链接无效」引导页 |
| 姓名含路径分隔符 / Windows 保留名 | 文件名消毒为安全值 |
| 二维码颜色注入（`javascript:alert(1)`） | 回退默认墨色，不进 SVG |
| 粘贴注入型 .vcf（`END:VCARD` 提前终止、转义分号） | 写入器转义保证只有一处 `END:VCARD`；解析器按转义切分 |
| 上传非图片 / 超 1MB 文件 | 类型与体积双重拒绝并提示 |
| localStorage 被手工投毒（畸形 JSON、超长值、控制字符） | `sanitize` 归一化，表单不崩溃 |
| http:// 明文图片 | schema 允许（vCard 标准如此），但 CSP `img-src` 仅 `https:`，页面内不加载；导出 .vcf 仍按标准引用，预览有 Logo 损坏回退（monogram）。属可接受降级。 |

## 五、残余风险与处置

1. **http:// 明文图片**：见上表，属有意收窄的可接受降级。
2. **style-src 'unsafe-inline'**：Tailwind v4 运行时与内联 style 属性所需；已收窄到 style，script 侧无 unsafe-inline/eval。
3. **真实环境联调**：多浏览器（Safari/Firefox）分享与剪贴板行为、iOS 通讯录导入、印刷店 PDF 接受度，需用户环境最终确认（自动化与 Chromium 实测已覆盖）。
4. **dev 工具链公告**：不进入产物；随上游版本例行跟进。

## 六、结论

本项目把「自包含」从承诺变为可执行的自动化守卫，并消除了新引入依赖的全部 critical 公告。生产依赖 0 漏洞，102 项测试（含 5 项安全守卫与 22 项解码回环）全部通过。
